# identity.rs

A call's nonce, minted from the generator the controller inherits from its
engine (the engine's `identity.rs`).

## fn mint_nonce
EVERY TOOL MINTS ITS NONCE FIRST, before any check, from its name and its
parameters, so every envelope, a refusal's included, carries one, on the client
as on the test driver. The name rides in the hash beside the parameters, so two
tools given the same parameters at the same instant still part. The parameters
hash as their raw NUON, nuval's; a set nuval can't write hashes as empty, the
name and the generator still parting it from the last.
