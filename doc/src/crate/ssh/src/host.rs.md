# host.rs

## fn init_engine
The engine's start on the config's namespace and homes and the scratch's
directories, as the MCP's `init_engine` starts its own. Once a process: the
engine's parameters are process-wide (the engine's `params.rs`).

## fn ensure_substrate
The MCP's substrate, made as its host makes it: the equip store, the default
purview, the plugin registry, and the builtins on a fresh store. A default
purview that can't be made is reported, as the MCP reports it, and the start
goes on.

## struct HostRoute
### fn answer
A pin is held here, the operator's live layer its watchdog reads. The config is
the MCP's, its Channel's settings living there, with grammar-ssh's own
supervisor lines in place of the MCP's, since those govern grammar-ssh's
operator. A send and a stop go up as they are; a remote send is prepared here
first, its files read where they are, and goes up inline.

## fn with_supervisor
The record's `supervisor` table replaced, its shape the MCP's, so a definition
reads one shape on any host.
